# 2/1（GIB 相容）制度表

這是 2/1 機器人照著叫的制度，依 [GIB System Notes](https://www.bridgebase.com/doc/gib_system_notes.php)（V40）整理，用我們自己的話寫。**出處**一欄：

- **官方**：GIB System Notes 或 GIB Bid Descriptions 有寫。
- **一般**：官方沒寫，用一般的 2/1 迫叫成局作法；列在 [`README.md`](README.md)「待在 BBO 上核對」。

規則程式在 `shared/robot/system/gib/`，每一節對應一個檔案；改了這張表要一起改規則與測試（`tests/engine/gib.test.ts`）。

## 0. 牌力與花色（官方）

| 特徵 | 定義 |
| --- | --- |
| 大牌點 | A 4、K 3、Q 2、J 1 |
| 總點 | 大牌點＋短門點：缺門 3、單張 2、雙張 1；短門裡有大牌的，那一門少算 1 點 |
| 花色品質 | **可叫**：5 張以上，或 4 張且有 A、有 K、或前五大（AKQJT）有三張；**可再叫**：可叫的條件多 1 張；**可兩次再叫**：再多 1 張；**強可再叫**：可兩次再叫，且前五大有四張或有 AKQ；**堅強**：6 張 AKQJxx／AKQTxx、7 張 AKQxxxx、8 張 AKJxxxxx 或 AKxxxxxx 以上 |
| 擋張（張數＋該門大牌點） | **半擋** 4（Qx、Jxx）；**可能有擋** 5 以上（Kx、Qxx）；**有擋**：有 A、QJx、該門 5 點以上，或 7 以上；**雙擋** 8 以上 |
| 控制數 | A 2、K 1 |
| 成局與滿貫 | 兩手合計約 25 總點就叫到成局（官方）；33 點小滿貫、37 點大滿貫（一般） |

叫品的**說明**由規則的「表示什麼」產生：同一個叫品有好幾條規則時，每一項取最寬的範圍；同一家叫過好幾個叫品時，每一項取最嚴的範圍（官方，見 `ROBOT.md` §6）。

**Jacoby 2NT 之後的開叫者再叫**（一般）：4 新花＝5 張好的第二門（AK、AQ 或 KQ 帶頭；5-5 一定有短門，所以先報第二門）；3 新花＝該門單張或缺門；3M＝18+ 沒有短門；3NT＝15–17 沒有短門；4M＝14 以下、沒有短門。

**其他高花答叫的細節**（一般）：4M 阻擊加叫要有單張缺門或 6 張王；1♥–1♠ 在有 3 張♥ 且 7–10 總點時改叫 2♥；跳到三線較低的花色要可兩次再叫的 6 張、M 不超過 2 張；已 Pass 的答叫者：二線新花 5+ 張 10–11 不迫叫，1NT 6–11 不迫叫，fit jump 是 5+ 張新花＋4 張王、10–12 總點。

**單加叫之後：雙向成局試探**（官方）

| 叫牌 | 表示 |
| --- | --- |
| 下一階（1♥–2♥–2♠、1♠–2♠–2NT） | 短門成局試探，短門在哪一門不明 |
| 答叫者再下一階（2NT 或 3♣） | 問短門在哪；開叫者叫出短門，短門是下一階的那門時叫回 M |
| 3M 以下的其他叫品 | 長門成局試探：3+ 張、有大牌（1♥–2♥ 之後 2NT 是 ♠ 的長門試探） |

**1M–1NT 之後開叫者的再叫**（一般）：二線新花 3+ 張（可能是 3 張低花）；1♠–1NT–2♥ 4+ 張♥；2M 6+ 低限；2NT 18–19 平均；3M 6+ 15–17；跳叫新花 19+ 迫叫成局。

**2/1 之後**：迫叫成局；開叫者再叫原花不保證 6 張（官方）；加叫答叫者的花色通常 4 張、偶爾 3 張（官方）。

## 9. Soloway 跳叫新花（`soloway.ts`，官方）

未 Pass 的答叫者、沒有插叫時，從一線跳到二線較高的花色（1♣–2♦／2♥／2♠、1♦–2♥／2♠、1♥–2♠）表示以下其中一種：

1. 強可再叫的花色、17+ 總點、4+ 控制、沒有旁門 4 張
2. 堅強花色、17+ 總點、4+ 控制，可能有旁門 4 張
3. 可再叫的花色、18+ 大牌點、4+ 控制、5332 或 6322
4. 可再叫的花色、17+ 總點、4+ 控制、4 張支持開叫者的花色

開叫者：再叫原花＝6+ 張；加叫答叫者或用 RKCB＝3+ 張支持；叫旁門＝不支持、該門至少 KQ；最便宜的 NT＝其他。答叫者第二次叫：類型 1、2 再叫自己的花色（低限而花色堅強時跳到成局）；類型 3 叫或加叫 NT；類型 4 沒有短門就加叫開叫者，有短門就叫短門（splinter）。

細節（一般）：類型的判斷順序是 4、2、1、3；說明是四種牌型的共同部分（可再叫的花色、17+ 總點、4+ 控制、迫叫成局）；「至少 KQ」照 GIB 的 8-4-2-1 算法，A 或 KQ 帶頭都算；「低限」是 18 總點以下；這本書排在答叫書之前，所以 1♥–2♠ 這類叫品一定是 Soloway，4 張支持的強牌也先跳叫新花而不是 Jacoby 2NT。
