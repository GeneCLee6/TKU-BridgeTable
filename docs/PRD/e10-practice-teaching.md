## 背景

BBO 的練習功能（和機器人練習、Just Declare、叫牌練習、搭檔叫牌練習、教學桌、Bridge Master 謎題）是很多人每天上線的原因。淡江牌桌本身就是為了社課：打完的牌要拿來討論，社員要練社團制度。E10 把「練習」和「教學」做成獨立的牌桌模式，並和淡江橋譜（社團的制度書）連在一起。

## 目標

- 條件發牌：指定某一家的點力、牌型、各門張數，用在練習桌、挑戰主題（E7）、教學桌。
- 練習桌：單人和機器人打，可隨時重發、撤回不限，不混進一般紀錄。
- 叫牌練習（只叫不打）與搭檔非同步叫牌練習。
- 教學桌：老師排牌、看四家、任意撤回、重打、講解。
- 賽後分析與謎題。
- 叫牌提示卡：叫牌時直接看到相關的淡江橋譜特約。

## 非目標

- 完整的線上課程平台（影片、作業、成績）。
- 機器人制度本身：歸 E5。

## 需求

- 條件語法放在 `shared/dealer.ts`，前後端共用；條件太嚴（抽不到）時回報錯誤，不會卡住。
- 練習桌的紀錄標 `mode=practice`，預設不出現在「全部社員」，自己可以篩選（E4）。
- 教學桌的老師是房主或有 `teach` 權限的人；學生可以入座或觀看。

## 驗收條件

- [ ] AC-10.1 — 條件發牌：可指定每一家的點力範圍、各門張數、平均牌型；內建預設集（1NT 開叫、高花開叫、滿貫牌、競叫牌、阻擊）；抽不到時明確回報。
- [x] AC-10.2 — 練習桌：單人＋三個機器人、可選條件發牌與機器人等級、可隨時重發、撤回不限；紀錄標示練習。（機器人不分等級，社長 2026-10-24 決定；「選等級」改成選 TKB 的制度）
- [x] AC-10.3 — Just Declare 練習：機器人代叫，真人只打莊。
- [x] AC-10.4 — 叫牌提示卡：叫牌時側欄「特約」分頁顯示目前情境相關的淡江橋譜特約，可開到橋譜。
- [ ] AC-10.5 — 叫牌練習：只叫牌不打，叫完顯示四家、DD 表與機器人建議的叫法，標出差異。
- [ ] AC-10.6 — 搭檔非同步叫牌練習：兩位社員輪流叫，不必同時在線；輪到誰有通知；完成後一起檢討。
- [ ] AC-10.7 — 教學桌：老師可指定牌組（PBN 匯入或從紀錄選）、看四家、任意撤回、重打同一副；可暫停並在牌桌上標示重點，學生端同步。
- [ ] AC-10.8 — 賽後分析：每副標出 DD 損失最大的幾步，附機器人在同一副的打法。
- [ ] AC-10.9 — 謎題：單人做莊題，答案以 DD 驗證是否保證成約；分級與進度。

- **條件太嚴抽不到**：先分配張數再發牌，嘗試上限後回報「條件太嚴」，並提示放寬哪一項。
- **練習紀錄淹沒正式紀錄**：練習預設不進「全部社員」列表。
