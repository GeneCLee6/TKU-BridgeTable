## 背景

牌桌的樣子照 BBO 做（`DESIGN.md` §1），讓社員不需要重新學。M0 經過 12 個 PR 的打磨：BBO 叫牌盒與中央叫牌表、停靠側欄、夢家花色欄、墩牌堆、出牌與收墩動畫、紙牌音效、六種語言、手機版東西兩家橫躺、可安裝的 PWA（`00-prd.md` F9、F14、F18、F19）。

M1 補上 BBO 有而我們還沒有的操作選項（二次確認、鍵盤），以及無障礙與新手導覽；M2 處理平板、牌的大小偏好與視覺回歸測試。新功能（挑戰、隊制賽、紀錄篩選）的畫面各自歸在那個 epic。

## 目標

- 保持「照 BBO」：任何新互動先看 BBO 怎麼做。
- 二次確認、鍵盤操作、螢幕閱讀器可以完整打完一副。
- 新社員第一次進牌桌就知道怎麼叫牌、攤牌、撤回。

## 非目標

- 新功能的頁面（挑戰大廳、隊制賽準備室、紀錄篩選）：歸 E7、E8、E4。
- 原生 App：歸 E12。

## 需求

- 顏色只來自 `styles/tokens.ts`，介面文字只來自 `strings.ts`，六種語言都要加（`CLAUDE.md` 硬性規則 5）。
- 牌、叫品、花色都有中文無障礙名稱；不只靠顏色表達狀態（`DESIGN.md` §1）。
- 手機（900px 以下）沒有水平捲動；每個改到版面的 PR 都要附 390px 寬的實測。
