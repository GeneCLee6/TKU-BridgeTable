# SAYC（Standard American Yellow Card）

TKB 可選的第三種叫牌制度（`e5-t51`，AC-5.11），規則在 `shared/robot/system/sayc/`。這份文件是我們自己的摘要，不抄 ACBL 的原文；細節以原文為準。

**來源**（都是公開的）：

- ACBL SAYC System Booklet（2006 年 1 月修訂版，SP3）：<https://www.acbl.org/documentlibrary/play/sayc_book.pdf>（寫這份文件時實際讀的是同一份 PDF 的公開副本：<https://zfelleg.useribm.hu/bridge/sayc_book.pdf>）
- ACBL SAYC 制度卡：<https://www.acbl.org/documentlibrary/play/sayc_card.pdf>

點數的寫法：booklet 的「點」多半包含牌型點，規則的 `hcp` 是大牌點，`tp` 是總點（`evaluate.ts`）。下表標 **判斷** 的是 booklet 沒寫或沒寫死、由我們決定的地方，集中列在最後一節。

## 1. 開叫

| 開叫 | 意思 |
| --- | --- |
| 1♥／1♠ | 5 張以上，各家都一樣 |
| 1♦ | 通常 4 張以上；4=4=3=2（♠♥♦♣）才會 3 張 |
| 1♣ | 3 張以上；低花 3-3 開 1♣、4-4 開 1♦ |
| 同長的長套 | 5-5、6-6 開高的那門 |
| 1NT／2NT／3NT | 15–17／20–21／25–27，平均牌型，可以有 5 張高花或低花 |
| 2♣ | 22 點以上，人工叫 |
| 2♦／2♥／2♠ | 弱二：6 張還可以的牌組、5–11 大牌點；太差的 7 張不夠開三線時也開弱二 |
| 三線、四線阻擊 | 看身價算墩數：有身價對無身價差 2 墩內、身價相同差 3 墩內、有利身價差 4 墩內 |

## 2. 1♥／1♠ 之後

| 答叫 | 意思 |
| --- | --- |
| 1♥–1♠ | 4 張以上、6 點以上，傾向沒有 ♥ 配合 |
| 1NT | 6–9，**不迫叫**，沒有 4 張 ♠（1♥ 時）也沒有 3 張配合 |
| 二線新花 | 10 點以上、**迫叫一圈**（不是迫叫成局），♣♦ 4 張以上，1♠–2♥ 5 張 **判斷**。未叫過牌的答叫者答應再叫一次，除非開叫者已經叫到成局 |
| 2M | 3 張以上、6–10 支持點 |
| 2NT | Jacoby 2NT，13+ 支持點，迫叫成局 |
| 跳新花 | 強跳，17+，有滿貫興趣 **判斷（點數）** |
| 3M | limit raise，3 張以上、10–11 支持點 |
| 3NT | 15–17、平均、2 張支持 |
| 4M | 通常 5 張以上、有單張或缺門、不到 10 大牌點 |

**開叫者的再叫**：低限（13–15）叫最低的無王、加叫同伴、一線新花或比開叫低的二線新花（不反序）、再叫原花；中等（16–18）跳加叫、跳再叫原花、反序；不反序的新花可以到 18；高限（19–21）跳無王、雙跳加叫或雙跳再叫原花、跳新花。

**Jacoby 2NT 之後**：三線新花是單張或缺門；四線新花是第二門長套；沒有短門時 4M 低限、3NT 中等（15–17）、3M 高限（18+）。

**答叫者的第二次叫牌**（一線答叫之後）：Pass、1NT、二線已叫花色是 6–9 止叫；2NT、三線已叫花色是 10–11 邀請；3NT、4M、5m 是止叫成局；新花迫叫；第四門花色迫叫一圈，可以是人工叫。

開叫者再叫 1NT 時：往上的二線新花（比答叫花色低）**不迫叫**；要迫叫成局必須跳新花到三線或反序。**沒有新低花迫叫。**

**二線答叫之後**：規則相同，但跳到三線加叫開叫者的第一門花色是迫叫成局（limit raise 要第一輪就叫）；二線回到開叫花色是 2 張的選擇，可以停。

## 3. 1♣／1♦ 之後

一線答叫由低往上（up the line）；加叫 1♦ 要 4 張、加叫 1♣ 要 5 張（競叫時可少一張）；2NT 13–15 迫叫成局、3NT 16–18。**不用倒轉低花**，低花沒有迫叫的加叫。

## 4. 1NT 之後

| 答叫 | 意思 |
| --- | --- |
| 2♣ | **不迫叫** Stayman，可以停在二線；之後叫三線低花是 5 張以上、有滿貫興趣 |
| 2♦／2♥ | Jacoby 轉換到 ♥／♠，5 張以上。開叫者完成，或 17 點 4 張時跳到三線 |
| 轉換之後 | Pass 到此為止；2NT、3M 邀請；新花自然、迫叫成局；3NT 請同伴選；4M 6 張以上定約 |
| 2♠ | 要開叫者叫 3♣：Pass 是 ♣ 爛牌，3♦ 是 ♦ 爛牌（開叫者 Pass） |
| 3♣／3♦ | 6 張以上，邀請 3NT |
| 3♥／3♠ | 6 張以上，有滿貫興趣 |
| 4♣ | Gerber。**對同伴任何 1NT 或 2NT 都是**，包括再叫；5♣ 問 K，其他叫品都是定約（包括 4NT） |
| 4NT | 自然，邀請 6NT |

**被插叫**：對方賭倍時所有約定照舊；對方叫牌時 Stayman、轉換都取消，叫牌自然，扣叫代替 Stayman 且迫叫成局。對方插叫在約定答叫之後，意思不變，主動叫牌表示真的有配合（1NT–(P)–2♦–(X)–2♥ 表示有 ♥，只有 2 張就 Pass）；再賭倍是處罰。

## 5. 2NT、3NT 之後

2NT：3♣ Stayman，3♦／3♥ 轉換，4♣ Gerber，4NT 邀請滿貫。3NT：4♣ Stayman，4♦／4♥ 轉換。

## 6. 2♣ 之後

2♦ 人工（可能是等待），2♥、2♠、3♣、3♦ 自然、迫叫成局、5 張以上且 8 點，2NT 是平均 8 大牌點。開叫者再叫 2NT（22–24）用 2NT 開叫的答叫；再叫花色迫叫到三線高花或四線低花（2♣–2♦–2♥–2♠–3♥ 不迫叫）。

## 7. 弱二之後

2NT 迫叫、有成局興趣（對方賭倍或叫牌也一樣）：開叫者低限（5–8）再叫原花，高限叫有 A 或 K 的花色，沒有就叫 3NT。加叫都是定約、可能是阻擊（RONF），3NT 定約，新花迫叫一圈、5 張以上。開叫者有 3 張或大牌雙張時加叫高花；沒配合時低限再叫原花，高限叫新花或無王。

## 8. 蓋叫與防守

| 叫品 | 意思 |
| --- | --- |
| 蓋叫 | 8–16 點；更強的牌先迫伴賭倍再叫長套 |
| 推進蓋叫 | 唯一迫叫的是扣開叫的花色，問蓋叫的品質：蓋叫者叫回最低的原花是低限，其他是有餘力（11–12 以上） |
| 1NT 蓋叫 | 15–18、平均、最好有擋；答叫只有 2♣ Stayman 是約定 |
| 跳叫蓋叫 | 阻擊，等於同線開叫的牌力：(1♠)–3♣ 像開叫 3♣ |
| 跳 2NT | 兩門最低的未叫花色 5-5 以上 |
| 扣叫（對方叫一門） | Michaels：低花時是兩門高花（8+）；高花時是另一門高花和一門低花（10+），推進者叫 2NT 問低花 |
| 扣叫（對方叫兩門） | 那門的自然叫 |
| 平衡位置 | 意思一樣，低限可以輕一點；平衡的 1NT 是 10–15 |
| 迫伴賭倍 | 對部分合約開叫（4♦ 以下）；對成局開叫（4♥ 以上）是處罰。推進者跳叫是邀請，要迫叫就扣叫 |
| 對阻擊開叫 | 叫花色、無王是自然；扣叫是 Michaels |

## 9. 我方開叫被插叫

原則：叫品意思跟沒人插叫時一樣，只是有時要選第二順位的叫品。

- **負性賭倍**到 2♠ 為止，保證至少一門未叫高花 4 張。1♣–(1♦)–X 兩門高花都 4 張；1♦–(1♥)–X 剛好 4 張 ♠（1♠ 保證 5 張）；1♦–(1♠)–X 4 張 ♥ 且 6 點以上，或 5 張 ♥ 且 5–10。二線以上叫高花是 5 張以上、11 點以上。
- **扣對方的花色**：有成局實力、方向未定，通常是加叫，迫叫成局。
- **對方迫伴賭倍**：一線新花迫叫，點數不限；二線新花不迫叫（6–10，通常 6 張）；2NT 是 limit raise 以上；再賭倍 10 點以上；跳加叫是阻擊；跳新花 6 張以上要定約。
- **再賭倍**還有兩種：己方在四線以上（或對方賭倍人工叫）是定約；在三線以下被處罰賭倍時是 SOS，請同伴換一門。
- **對方用約定**（Michaels、不尋常 2NT）：賭倍表示 10 點以上、多半平均；扣對方表示的花色迫叫成局。
- 任何插叫都會取消非競叫用的約定。

## 10. 滿貫

- **黑木**（4NT）問 A：5♣ 0 或 4 張、5♦ 1、5♥ 2、5♠ 3。5NT 問 K，保證四張 A 都在，同樣按步答（6♣ 起）。不是關鍵張問叫。
- **Gerber**（4♣）：4♦ 0 或 4 張、4♥ 1、4♠ 2、4NT 3；5♣ 問 K：5♦、5♥、5♠、5NT。
- **大滿貫迫叫**：跳到 5NT，有兩張 AKQ 叫七線，否則六線。

## 11. 首攻與信號

booklet 寫的：大牌連張領頂張；對王牌合約 AKx 領 A；第四張；三張小牌對王牌領小、對無王領大；四張以上沒大牌領第二大。信號「大的鼓勵，小的不鼓勵」，張數是高小偶數。

**TKB 的出牌與其他制度共用**（ROBOT.md §3.2）：SAYC 不另寫一套打牌，所以制度卡上的首攻與信號列的是 TKB 實際的打法，可能跟 booklet 這一節有出入（例如四張以上沒大牌領第二大）。

## 12. 判斷

booklet 沒寫或寫得寬的地方，我們的選擇（`ROBOT.md` §6.16 也列了影響）：

| 地方 | 選擇 |
| --- | --- |
| 開叫的下限 | 12 大牌點，或 11 點符合 20 法則；各家都一樣。booklet 沒寫下限，只說低限是 13–15 點，所以規則寫成 11–15 大牌點 |
| 再叫 13–15 | 規則用 `hcp: 11–15`（上一條），無王再叫 11–14（15 平均已開 1NT） |
| 第三家輕開、四張高花 | booklet 允許判斷；機器人不做 |
| 第四家 | 不開弱二、不阻擊；也不用 15 法則 |
| 2♣ 的「牌力相當」 | 機器人只用 22 大牌點以上 |
| 三線阻擊的大牌點 | 5–10 |
| 弱二「還可以」的牌組 | 有 A、K 或 Q 之一，且前五大至少兩張；旁門 4 張高花不限制 |
| 18 點平均 | booklet 寫跳無王是 19 以上；機器人 18–19 跳 2NT，否則 18 平均沒有叫品 |
| 1♠–2♥ | 5 張以上（booklet 只明寫 ♣♦ 4 張） |
| 二線新花選哪門 | 長的；4-4 叫低的、5-5 叫高的 |
| Jacoby 2NT 的張數 | 4 張以上；3 張只有在沒有二線花色可叫時（否則先叫新花再跳加叫，booklet 說那是迫叫成局） |
| 12 支持點、3 張、沒有二線花色 | 3M，所以 limit raise 的說明是 10–12（booklet 是 10–11） |
| 強跳新花 | 17 點以上、牌組最長、5 張以上 |
| 由低往上 | 最長的先叫，等長叫低的（4♦4♥ 叫 1♦） |
| 1♣ 的 10–12 平均、無四張花色可叫 | 1NT，所以對低花的 1NT 寫 6–12 |
| 3m | limit raise（booklet 只說沒有迫叫的加叫） |
| 叫牌沒寫的 2NT 答叫 1NT | 8–9 自然邀請 |
| 1NT 之後的 Stayman 點數 | 有 4 張高花 8 點以上；8 點以下只有 ♣ 短、高花至少 3-3 才叫（不迫叫，可以停） |
| 1NT–3♣／3♦ | 6–9 點；2♠ 是 0–5 |
| 3♥／3♠ 滿貫興趣 | 14 點以上 |
| 轉換之後、Stayman 之後的 4NT | 自然邀請（只有直接加叫的 4NT 是 booklet 明寫，其他是判斷）；有配合想打滿貫的牌由滿貫檢查直接叫 |
| 1NT 被賭倍的再賭倍 | 10 點以上、平均 |
| 對方在 1NT 上叫牌 | 賭倍是處罰（8+）；二線新花不迫叫（0–9），三線新花迫叫成局 |
| 競叫時的跳加叫 | limit raise（「叫品意思不變」），不是 2/1 那種阻擊 |
| 一線蓋叫的張數、二線蓋叫 | 5 張以上；二線要 10 點或 6 張 |
| 迫伴賭倍的最低牌力 | 12 點配牌型，或 17 點以上任何牌型；平衡位置 9 點 |
| 不尋常 2NT 的點力 | 8 點以上，不分身價 |
| 賭倍 1NT | 處罰（15+）。booklet 字面上說部分合約開叫的賭倍都是迫伴，但沒有人對 1NT 這樣打；其他對 1NT 的叫品都自然，2NT 兩低花 |
| 對阻擊的最低牌力 | 迫伴賭倍 13（四線 15）、蓋叫 12–18、3NT 16–21 |
| 負性賭倍到 2♠ 之後 | 賭倍是處罰（4 張以上、10 點以上） |
| 沒有未叫高花時的負性賭倍 | 表示兩門低花 |
| 黑木被插叫 | 依「插叫取消約定」不答 |
| 黑木的時機 | 由後備規則判斷有滿貫才問 |
| Gerber 的時機 | 機器人只在有 6 張以上、夠滿貫時用；其他是真人叫了才讀 |
| booklet 沒寫到的叫牌過程 | 由跟 2/1 共用的後備規則（`gib/fallback.ts`）找配合與成局，叫品的說明也由它產生 |
| 被插叫後的 2NT（一線、二線都一樣） | 自然 12–14（booklet 的例子是二線），3NT 15 以上，1NT 6–9，都要有擋 |
| 競叫時低花的單加叫 | 少一張（♦ 3 張、♣ 4 張），但有未叫高花 4 張時先賭倍或叫高花；limit raise 要足張 |
| 沒有配合的成局牌 | 也可以扣對方的花色（13 點以上，booklet：方向未定），所以說明不一定有張數 |
| 成局牌答 1♠／1♥ 蓋叫後的 Jacoby | 被插叫就取消，2NT 是自然 |
| 4♣ 的 Gerber 例外 | Jacoby 2NT、不尋常 2NT 之後的 4♣ 不是 Gerber（「1NT 或 2NT」只算自然的） |

**沒有寫的**：booklet 也沒有 Smolen、Texas、低花 Stayman、低花轉換、Drury、支持性賭倍、回答性賭倍、Lebensohl、Cappelletti、DOPI、RKCB，所以 SAYC 的機器人都不用（跟 2/1 不同）。
