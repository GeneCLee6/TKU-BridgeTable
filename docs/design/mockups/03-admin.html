03 社團管理頁 · 現在 vs 提案

同一個狀態：剛按完「社團設定」的儲存；一筆待審核的申請。桌機 1280×1180，縮成 60%（現在的頁面下方還有「新增社員」「牌桌」兩張卡，沒入鏡）。

  1. 左側分區導覽（桌機，可捲到該區、標出所在的區），手機版收成頁面頂端的下拉選單；待審核數用金色徽章。
  2. 每張卡片分「標題列／內容／頁腳」三層；儲存、新增等送出按鈕一律放在卡片頁腳右側。
  3. 表單用固定格線：標籤欄 180px、輸入欄 320px，說明文字在輸入框正下方；手機版標籤改在上方。
  4. 「已儲存」不再是頁首一行綠字，改成右下角 toast（4 秒自動消失、可關閉、螢幕閱讀器會念）。
  5. 欄位錯誤顯示在該欄下方，輸入框框線變紅並加圖示與文字，不只靠顏色。
  6. 社員表的列操作統一成「重設密碼」＋「⋯」選單（設為管理員、刪除社員…）；危險動作只在確認那一步才用實心紅按鈕。數字欄靠右對齊、日期改成相對時間。
